# Colibri AI Agent & Companion

## Overview

**Colibri** is a lightweight, locally‑run AI companion built for Apple Silicon (M1/M2) Macs. It leverages the **Metal zero‑copy engine** for fast tensor operations and integrates the **Qwen‑3.6‑35B‑A3B** model for high‑quality responses. The system is orchestrated with **LangGraph**, providing a zero‑dependency state‑graph workflow engine. Colibri presents the **Jimmy bot persona**, an English‑only, concise assistant, and exposes a **ToolRegistry** that unifies Internet, Vision, Audio, RAG, and code execution tools.



---

## Architecture

- **Apple Silicon M1/M2**: Optimised for ARM64 with native Metal kernels (`src/backend_metal.*`).
- **Metal Zero‑Copy Engine**: Direct GPU memory sharing eliminates unnecessary copies, dramatically reducing latency for the Qwen3.6 model.
- **Qwen‑3.6 Model Integration**: The model is served via the `coli serve` command and accessed through the `HttpTransport` implementation.
- **LangGraph Orchestrator**: Defined in `src/ai/graph.py`, it manages agent state, tool execution, and checkpointing via SQLite (`ColibriSqliteCheckpointer`).
- **Jimmy Bot Persona**: Defined in `src/ai/persona.py` (fallback in `graph.py`), providing English‑only prompts and behaviour.
- **ToolRegistry**: Central registry (`src/ai/tools/__init__.py`) exposing:
  - Internet & research tools (`web_search`, `fetch_webpage_content`, etc.)
  - Vision/OCR (`vision.py`)
  - Audio I/O (`audio.py`)
  - RAG memory (`rag.py`)
  - Safe Python code execution (`code_runner.py`)

## Installation

```bash
# Clone the repository
git clone https://github.com/your-org/colibri.git
cd colibri

# Install Python dependencies (requires Python ≥3.10)
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Install Metal kernels (macOS only)
# The Makefile builds the Metal backend for the current architecture
make -C src backend_metal
```

> **Note**: The Metal build automatically detects the Apple Silicon architecture and compiles the zero‑copy kernels.

## Usage

Run the companion from the command line:

```bash
# Start the Qwen3.6 model server (requires the `coli` binary)
coli serve qwen36-35b

# In another terminal, invoke the CLI
colibri-cli "Hey Jimmy, what’s the weather in Tel Aviv today?"
```

The CLI (`src/ai/cli.py`) sends the prompt to the local server, which routes it through LangGraph, pre‑fetches local memory, and calls the appropriate tools via `ToolRegistry`.

### Example with Tools

```python
from src.ai import run_agent, AgentConfig, TOOL_REGISTRY

config = AgentConfig(model="qwen36-35b", base_url="http://localhost:8080")
result = run_agent(
    config=config,
    prompt="Hey Jimmy, give me a quick summary of today's weather in Tel Aviv.",
)
print(result.answer)
```

## Development

- **Run tests**: `pytest -q tests/`
- **Add new tools**: Register them in `src/ai/tools/__init__.py` and update `TOOL_REGISTRY`.
- **Extend the persona**: Modify `src/ai/persona.py` and rebuild the system prompt.
- **Metal debugging**: See `docs/metal.md` for kernel profiling.
